# J.A.R.V.I.S. — голосовой помощник для Windows

Джарвис слышит тебя, отвечает голосом, управляет компьютером и выполняет **протоколы** — цепочки действий по одной фразе.

> «Джарвис, замути бимку» → «Запускаю Бим Энджи Драйв, сэр. Пристегнитесь.» → BeamNG.drive открывается в Steam.

## Как установить (просто)

1. Открой [страницу загрузки](../../releases/latest) и скачай **Jarvis-Windows.zip**.
2. Распакуй архив (правой кнопкой → «Извлечь всё»).
3. Запусти **Jarvis.exe** в папке `Jarvis`.
   Если появится синее окно «Windows защитила ваш компьютер» — нажми **«Подробнее» → «Выполнить в любом случае»** (так бывает со всеми программами без платной подписи).
4. Подключи нейросеть (бесплатно, 1 минута):
   - зайди на [console.groq.com/keys](https://console.groq.com/keys), войди через Google;
   - нажми **Create API Key**, скопируй ключ;
   - в Джарвисе: **Настройки → Ключ** → вставь → **Проверить связь**.

Всё. Скажи: **«Джарвис!»** — он ответит «Да, сэр?».

## Что умеет

| Скажи | Что будет |
|---|---|
| Джарвис, замути бимку | запустит BeamNG.drive в Steam |
| Джарвис, запусти кс / доту / гташку | запустит игру (понимает сленг) |
| Джарвис, открой телеграм / дискорд / блокнот | запустит программу |
| Джарвис, закрой хром | закроет программу |
| Джарвис, громкость 40 / тише / выключи звук | звук |
| Джарвис, следующий трек / пауза | музыка |
| Джарвис, включи lo-fi на ютубе | найдёт и включит видео |
| Джарвис, какая погода в Киеве | погода и прогноз |
| Джарвис, как там компьютер | процессор, память, диски |
| Джарвис, напомни через 10 минут выключить чайник | таймер |
| Джарвис, сверни все окна / сделай скриншот | окна и экран |
| Джарвис, выключи компьютер | спросит подтверждение |
| Джарвис, кто такой Тони Старк? | просто поговорит |

После ответа можно 8 секунд продолжать разговор без слова «Джарвис».

## Протоколы

Вкладка **Протоколы** → **+ Новый протокол**:
- придумай фразу (например «протокол гости»);
- добавь действия: сказать фразу, запустить игру Steam, открыть программу/сайт, нажать клавиши, громкость, пауза, команда PowerShell, сон/выключение, вопрос нейросети;
- сохрани — и всё работает.

Вкладка **Игры Steam** показывает все установленные игры: кнопка **+ Протокол** делает команду запуска в один клик.

Готовые протоколы: «Бимка», «Игровой режим», «Режим работы», «Вечеринка», «Чистый лист», «Гости», «Спокойной ночи».

## Голос

По умолчанию — бесплатные нейроголоса Microsoft с «компьютерным» эффектом. В настройках можно выбрать британский голос как в фильме (Ryan), русский, украинский, поменять скорость и высоту.
Можно подключить ElevenLabs (свой ключ + Voice ID любого голоса из их библиотеки).

## Запуск из исходников (для программистов)

Нужен Python 3.12: `install.bat`, потом `start.bat`. Или:
```
pip install -r requirements.txt
python jarvis.py
```
Проверка: `python tests/smoke_test.py`.

Настройки и протоколы хранятся в `%APPDATA%\Jarvis`.
